# مسار — منصة متابعة الرسائل العلمية

مساحة لكل باحثة تتابع فيها رسالتها مع مشرفتها.

- الباحثة تسجّل بإيميلها وكلمة مرور، وتنفتح لها مساحتها الخاصة بهيكل رسالة جاهز.
- المشرفة تدخل من رابط خاص ترسله لها الباحثة، بدون تسجيل: تقرأ وتعلّق وتعتمد أو تطلب تعديل.
- كل مساحة مقفولة على صاحبتها بصلاحيات قاعدة البيانات (Row Level Security).
